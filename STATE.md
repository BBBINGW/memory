## MAIN OBSTRUCTION

BGV ciphertext components only have canonical meaning modulo q; a chosen integer representative incurs `qk(B)` in decryption, with k depending on the *secret key*. dBFV §4.6 short digit lattice `L` uses congruence modulo plaintext p, but q is a unit modp, so reducing ciphertext integer component lifts modL can change the correct centered modq digit plaintext even with zero noise (I179). Previous attempt to identify L *inside* coefficient ring modq kills quotient altogether (I178). AP13 can publicly convert lsb/msb encodings, but that is a known transform with plaintext scale bookkeeping and says nothing about a native BGV replacement of dBFV's fractional modulus & error growth. Any meaningful new scheme requires handling q-carries (potentially encrypted), and proving resulting KS/Mul/ModSwitch error & performance. This has not been attempted.
