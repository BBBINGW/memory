## Universal rank obstruction for lambda=1 [DERIVATION]

On Boolean input cube `{0,1}^4`, write `L=Σ_{i=0}^3 alpha_i x_i ∈ F3` and `phi=psi(L)`. **Every** psi:F3→F3 has a polynomial representation `psi(z)=a z² + b z+c` because polynomial evaluation degree≤2 is bijective on 3 points (nonlinear iff a≠0). In the Boolean coordinate ring `F3[x0,x1,x2,x3]/(xi²−xi)`, phi has Boolean multilinear degree≤2.

Let `S=span_F3(1,x0,x1,x2,x3,phi)` (dim≤6). Original Eq(1), augmented by an arbitrary publicly known additive constant and any D, lies inside the **degree-two product space** `S·S=span{u·v : u,v∈S}`. Because `phi² = (psi(L))²` is STILL some function `eta(L)` on F3, it has a degree≤2 polynomial representation in L and thus is multilinear degree≤2 in the original Boolean variables. All other basis products are degree≤2 except `x_i phi`, which have degree≤3. Hence **EVERY** `f∈S·S` has Boolean multilinear degree≤3. Four-bit parity `f=x0 XOR x1 XOR x2 XOR x3` has unique F3 multilinear representation with coefficient of `x0*x1*x2*x3` equal to `(-2)^(4−1)=−8 ≡1 mod3`, hence degree4 and is **NOT** in S·S for ANY psi, alpha or D and any number of nonnested products. Parity is balanced (8 zeros and 8 ones), and can be a bit of an invertible 4-bit linear S-box (e.g. `(x0,x1,x2,x3)→(x0⊕x1⊕x2⊕x3,x1,x2,x3)`), so no 'unbalanced LUT' loophole.

**Stronger bound:** Base multilinear degree≤2 space has dimension `1+4+6=11`. Each cubic part of `x_i phi` is `2a Σ_{j<k, j,k≠i} alpha_j alpha_k x_i x_j x_k`; for every degree-three monomial with triple {i,j,k}, the weighted sum `Σ_i alpha_i * (cubic part of x_i phi)` has coefficient `3*(2a)*alpha_i alpha_j alpha_k=0 mod3`. If alpha≠0 this is one NONTRIVIAL relation among four cubic contribution vectors: cubic dimension≤3. If alpha=0 all cubic contributions vanish. Since phi² has no cubic or quartic term, **dim(S·S)≤11+3=14** uniformly over all 81 alpha and 18 nonlinear psi. Thus ANY source-shaped A with lambda=1, even after adding free constant1 and arbitrary t,D, has `rank_F3(A)≤14<16`. This bound is a property of the restricted one-step Eq(1) circuit class only; the claim does NOT extend to **nested** encrypted products, different embedding primes, or more than one atomic function.
