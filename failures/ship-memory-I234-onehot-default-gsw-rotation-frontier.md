## The full candidate, secret domain, and ideal invariant [DERIVED]

For input `ct=Enc_s(m)` with sign convention `Dec_s(a,b)=b+a*s`, and per-group hidden onehot `beta0,...,beta_(B-1)`, generate only `B−1` standard rank2 GGSW/switching gadgets with BOTH message columns `(beta_d*s,beta_d)` but **output secret s** (the same as the input), for d=1,...,B−1. GGSW-style external product `U_d=ExtProd(Enc_s^GGSW(beta_d),ct)` decrypts to `beta_d*m` under s. Build standard ordinary automorphism key `ATK_{g_d}` for each distinct public d over all supports; `R_d=GLWEAutomorphism(U_d,g_d,ATK_g)` decrypts to `sigma_g(beta_d*m)` under s, i.e. `beta_d sigma_g(m)`. Output:
```
  out = ct + sum_{d=1}^{B−1}(R_d−U_d).
```
Ideal `Dec_s(out)=m+sum beta_d(sigma_gd(m)−m)=beta0*m+sum_{d>0}beta_d sigma_gd(m)`, using `sum_d beta_d=1`; exact required B-way MuxRot and **correct output secret s**. No high q896 controls, no key-to-key stored-GGLWE reconstruction, no extra ct×ct multiplication or multiplicative level in ideal algebra. Introduces `h*sum(B−1)=352` **ONLINE** ordinary GLWE automorphism key switches, distinct from I229's `6336` offline/on-demand *key-to-key* switches. Associated new keys and original remaining βs keys are correlated, requiring an explicit **joint evaluation-key security assumption/proof**; don't claim inherited source security.
