## Exact fatal leakage derivation [DERIVED]

Fix group g and candidate d, and row i=1 of **second, constant-input** source HMux gadget column (the first β*s column is irrelevant). At this fixed candidate all support indices j have the same output secret `t_d`. With `G_i=2^52`, symmetric GLWE encryption sign convention:
```
C_j=(a_j,b_j),  b_j=-a_j*t_d+G_i*beta_{j,d}+e_j  mod 2^520.
```
Proposed MASK-sharing format chooses `a_j=a_k=a` for all support pairs j,k at fixed group,d,i, but samples each e_j independently, |(e_j)_l|<=19. The public difference is
```
b_j-b_k = G_i (beta_{j,d}-beta_{k,d}) + (e_j-e_k)  mod 2^520.
```
Take the constant coefficient `l=0`; encryption targets β times constant 1. Difference of errors at l=0 has absolute <=38, while `G_i=2^52≫38` and well within centered modulus 2^520. Thus an evaluator distinguishes **-1, 0, +1 exactly** by rounding centered (b_j-b_k)_0 / G_i, with guaranteed no threshold confusion. If for a fixed candidate d at least two support indices have different β values (legal sparse support choices), observing one positive difference labels the 1 support and 0 support. Comparing to the identified 0 reference recovers **all h support bits β_{j,d}**, and repeating for every radix candidate recovers complete onehot digits. No expensive lattice attack, no access to secret, no joint KDM assumption necessary; public body differences alone suffice. If all βj happen to coincide for a given candidate, the attack may not assign absolute 0/1 labels from that candidate alone; nevertheless H235's general privacy claim is falsified by legal varying choices. Important: no claim source SHIP actually has shared a, it DOES NOT.
