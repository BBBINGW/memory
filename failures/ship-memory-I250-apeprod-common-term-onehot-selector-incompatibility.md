## Formal obstruction [DERIVATION]

At one fixed support j and b≥2 SHIP candidates, take onehot `beta_d=1[d=d*]`. The source key's scalar gadget-column row d at gadget G encrypts the constant polynomial `G beta_d` (plus bounded RLWE noise), under t_d. To share a B-J common `GLWE(mu)` across all d while varying only a **PUBLIC Galois automorphism ψ_d** and performing NO selector-dependent operations, the plaintext in each such gadget column would have to equal `σ_{ψ_d}(mu)`, up to low encryption noise.

In any negacyclic cyclotomic ring `R_Q=Z_Q[X]/(X^N+1)`, for every odd unit g mod2N and every f(X), the **constant coefficient is invariant** under σ_g:X→X^g: the only monomial mapping to X^0 or -X^0 is j=0 among j∈[0,N). Therefore `const(σ_{ψ_d}(mu))=const(mu)` for all d, including if mu is nonconstant. But onehot candidate payload constants require distinct `G beta_d`; e.g. radix4 `(0,0,G,0)` for d*=2. There is NO single mu whose automorphism images yield those constants, assuming no additional secret-dependent selection/bilinear operation.

Even if “equality” were relaxed to **correct decryption within per-row coefficient noise magnitude E**, target plaintext scalar for selected and unselected candidates differ by circular torus distance `dist_Q(0,G)=min(G,Q-G)`; a common scalar phase could satisfy both only if `dist_Q(0,G)≤2E`. In source-like toy q=2^40, G=2^32, E=19, dist=4294967296>38, so impossible by an overwhelming margin. Source's actual top gadget G (e.g. 2^468 under physical q2^520) also satisfies this strong separation. No key-recovery attack needed. This is a **conditional obstruction to direct column reuse**, NOT a lower bound for arbitrary transformed HMux circuits or schemes that supply selector-dependent new ciphertexts.

**B-J's 'remove ordinary automorphism key switching' also has no matching step to remove in existing source SHIP HMux**: the source performs DFT-domain automorphism after rank2 external product, with no ordinary KSK; adaptation would require changing the *whole secret-domain architecture*, adding new keys/security/latency analysis, not a drop-in memory reduction.
