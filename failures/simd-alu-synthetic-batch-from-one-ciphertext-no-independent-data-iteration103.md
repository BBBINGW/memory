## ONE hypothesis and cheapest decisive rank test
[HYPOTHESIS, FAIL] When only ONE fully packed arithmetic ciphertext is available, perhaps one can use native Z-slot rotations, masks or replicas to create B=n/w 'virtual' arithmetic ciphertexts and realize the same B-fold amortized useful throughput as processing B truly independent ciphertexts, without more independent input plaintexts.
[FALSIFIER] Simple payload rank/entropy conservation: from S=N/n independent words, arbitrary linear rotations/masks/copies cannot create BS=N/w independently selectable words. A synthetic batch still holds ≤S independent payloads even if all B ciphertext handles appear allocated, so d=n/w bootstrapping passes for it cannot provide B-fold benefit PER INDEPENDENT ORIGINAL WORD, without other real source ciphertexts.

## DERIVATION
Let source x∈(Z_{2^n})^S with S=N/n independent Z-slots. A Z-slot permutation is an S×S permutation; masking is diagonal and re-encoding into B ciphertexts is a linear map A:(Z_{2^n})^S→(Z_{2^n})^{BS}, induced by stacked permutation/mask/copy matrices. Regardless of ring field issues, over any residue ring, the output module is generated by ≤S elements, and in the 0/1 linear toy rank(A)≤S; repetition cannot generate B·S arbitrary independent original plaintext words. Subsequent LUTs can compute deterministic functions of these S words, but cannot add externally independent message information. To compare fully independent data, B original ciphertexts are needed (barring alternative compression relying on data structure or lower entropy).
For n64,w4,N=65536: S=1024, B=16, fully useful batch capacity B·S=16384 **independent** machine words; one source yields at most1024. Full-load useful-payload occupancy of synthesized batch ≤1/16. One standalone A2B needs B=16 iterative bootstrapping passes; splitting/duplicating one source into B synthetic cores still needs B passes, so no speedup from amortized pass-count alone for the original independent data and incurs additional masking/rotation.
PARTIAL occupancy subtlety: with 2..B−1 **real independent** ciphertexts, B-A2B can still provide a partial benefit relative to separately converting them; FAIL result is only about trying to generate full B-fold independent throughput from ONE source.
