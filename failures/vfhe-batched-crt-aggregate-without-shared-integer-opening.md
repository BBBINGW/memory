## One primary hypothesis / decisive falsifier
[HYPOTHESIS — FAIL] For vector-length m, instead of per-digit external opening proof, choose one random linear form alpha, let separately committed CRT-field vectors h_k produce aggregate S_k=Σ alpha_i h_ki mod field, then treat CRT(S_1,...,S_mu) as a single shared aggregate to guarantee h_k are projections of one external Boolean vector b. This is alleged to save expensive external linking.
[FALSIFIER] Fix two field vectors inconsistent with a previously committed b; show that for any realized alpha, prover can CRT-compose field aggregate results into a single A passing ALL modular checks without linking to b. Cheapest test = one fixed m3 two-prime numerical witness and exact arithmetic.

## Concrete fatal CRT aggregate attack (not RS encoding)
Take p=29, p'=41, q=1189. True externally committed b=(0,0,0). Separately bound component vectors h29=(0,0,0), h41=(1,0,0), both legal binary vectors yet inconsistent with b and each other. Choose alpha=(1,1,0) after commitments. Field aggregates S29=0, S41=1. Compute
 A_fake = CRT(0 mod29,1 mod41)=493 mod1189.
Then A_fake mod29=0=S29, A_fake mod41=1=S41. **All tests that merely check A_fake's field residues succeed; the claim of one shared external vector is FALSE** because the genuine exact integer aggregate is Σ alpha_i b_i=0, not 493.
More strongly, for ANY alpha and any separately chosen field aggregates, CRT's product isomorphism always supplies an A_fake. One post-challenge CRT value cannot by itself bind vector semantics even though all branch inputs were committed before the challenge. A ring-element commitment to A_fake, if made only AFTER the challenge, does not fix this. The subtle problem is absence of proof tying A to the prior external vector commitment.

## Honest completeness caveat: noncommuting canonical lifts
External integer input b=(1,1,1), powers weight alpha=(1,7,49): true integer sum T=57. Its field reductions: T mod29=28, mod41=16. Reusing the canonical representative 28 from the first field in the second gives 28≠16. Thus `(T mod29) mod41` is NOT `T mod41`. By contrast integer T=57, viewed directly in both fields, is consistent; CRT(28,16)=57 mod1189. This is the exact distinction from I65's external-field RS noncommutation: NO claim that all batched checks across different characteristics fail; only naive inter-field canonical-lift conversion fails.

## Corrected CONDITIONAL lemma: binary masks, one globally certified integer aggregate
Assume an external computationally binding (and hiding) commitment C_b to b=(b_i)∈{0,...,beta−1}^m with genuine commitment extraction/binding and range proof; every field-specific h_k=(h_ki)∈F_k^m is bound by a field PCS BEFORE alpha. Verifier chooses alpha∈{0,1}^m uniformly AFTER ALL commitments. Let honest exact *integer* A=Σ alpha_i b_i∈[0,m(beta−1)] and **require a sound external proof that this exact integer A is indeed derived from the fixed C_b**. Require field PCS/sum-check opening that Σ alpha_i h_ki = A*1_Fk in EACH F_k, with explicit reduction of the same canonical integer A to each prime field.
For fixed inconsistent h_k, δ_i=h_ki−b_i*1_Fk is nonzero for some j. Condition on all alpha_i except alpha_j. Values C and C+δ_j are distinct in F_k, so at most one of the two alpha_j values passes. Therefore
  Pr_alpha[Σ alpha_i h_ki = A*1_Fk] ≤1/2.
With t independent mask repetitions (and vectors fixed *before* all masks), the probability that ALL t checks pass for a fixed inconsistent field is ≤2^(−t); if some field is wrong, select that fixed field and hence the GLOBAL false-positive probability is also ≤2^(−t) (μ2^(−t) union bound is true but looser). This bound is valid even over extension fields and without pmin>m, since the exact A is embedded directly in each field via integers. It is **NOT** valid if the prover chooses h after seeing alpha or if the 'A' checked is just an unlinked CRT aggregate.
Exact exhaustive test for m3, p29 over all 26 nonzero ternary delta∈{−1,0,1}^3 and all 8 binary masks: max accepted masks=4/8; tight. No simulation is a cryptographic proof; algebraic proof above is rigorous under commitments+certified external A.
The external proof can be instantiated over a separate prime field P>m(beta−1) so equality in F_P with *range/bitness* constraints gives the exact integer sum (no wrap); otherwise an explicit integer/carry arithmetic proof must prevent P-wrap. The field-side result is compared to the same exact A reduced independently mod each p_k, never by iterated prime reductions. This source-of-A bridge is precisely the remaining potentially costly step.

## Critical privacy obstruction
Publishing the aggregate A in the clear is NOT zero knowledge in general. With m3 and fixed b0=(0,0,0), A=0 under all 8 binary masks; for b1=(1,0,0), A=1 under 4 of 8 masks. Public A therefore distinguishes hidden witness values and may leak Hamming information even with a hiding vector commitment. A real repair must hide A (or prove a cross-characteristic committed-aggregate relation in ZK), which reintroduces a nontrivial linking protocol. Do NOT present this conditional arithmetic test as a complete ZK solution.

## Impact / research pivot decision
