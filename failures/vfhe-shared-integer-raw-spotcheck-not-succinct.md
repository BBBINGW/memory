## Single primary hypothesis and minimal decisive test
[HYPOTHESIS — FALSIFIED] A commitment to ONE globally shared integer digit vector z=(z_1,...,z_m) with z_j∈[0,β), plus uniformly sampled t≪m *raw* coordinate openings that check z_j*1_R=h_j (equivalently every CRT factor), is a succinct 128-bit-sound repair for original `Pi_beta_range` at practical m.
[FALSIFIER] One adversary with a SINGLE illegally CRT-mixed h_j, but legal fieldwise projections, and global honest external z (all zeros), so the raw comparison detects cheating only if the one corrupted position is checked; acceptance probability 1−t/m for t positions chosen uniformly without replacement after binding.
[CHEAPEST TEST] Exact hypergeometric probability (single exceptional position) and integer arithmetic for paper-style N=16384, c=1, ell=1 and t counts. No PIOP or FHE reimplementation; adversarial h remains the SAME e=667 from I61, not a fresh toy instance.

## Exact attack and conditional calculation
[DERIVATION] Take R=Z_1073[X]/(X^8+1), with CRT prime factors 29 and37 and scalar idempotent `e=667`, e mod29=0, e mod37=1, e∉{0,1}; this is I61's already independently verified N8,d4 ring. Let common integer commitment z=(0,...,0) of length m. Define h_j=0 for every j except one j*, where h_j*=e. Each CRT field projection of h lies in table {0,1}; the original componentwise Pi_beta_range still accepts using authentic CRT-glued field memory traces, but the desired global scalar digit property fails, and external equality z_j=h_j fails exactly at one position. Define v_i by accurate recomposition Eq.(22) of this h, so Pi_decomp remains true; choose an index corresponding to coefficient X^0 so public range relation false.
If prover binds h and z BEFORE verifier samples t distinct uniformly random indices, event of detection is `j* in T`, probability exactly t/m. Consequently
 `Pr[accept] = (m-t)/m`.
For any m∈[2,2^128−1], t=m−1 still yields acceptance probability 1/m >2^-128, therefore a 128-bit soundness bound against this attack forces t=m. If sampling WITH replacement, acceptance is (1−1/m)^t, even worse for the same t.
The calculation is optimistic: assumes each sampled position can be checked *perfectly* against ALL CRT components at no additional cost; actual Merkle / PC openings and cross-characteristic residue checks consume time/bytes.

## Cost/novelty/scoping verdict
[FAIL] Shared externally committed integer representation **alone is semantically strong enough** to define desired digit. But connecting it to every ring digit by only a handful of unencoded raw openings is weak: one mismatch evades t queries with probability 1−t/m; sufficient worst-case soundness requires Θ(m) external checks. This is a basic property-testing/uncoded commitment limitation, not a new general cryptographic impossibility or publishable result. Reusing the original ring PC commitments does not fix it: their per-field soundness is only about their own committed functions, not global digits.
[OPEN] An ECC/PCP-proximity or cross-characteristic proof system could propagate one original digit mismatch to Ω(m) encoded positions, allowing a modest sample budget; however consistency of a SINGLE external integer codeword and each p_i-field codeword must be proved (not assumed). Non-native field gadgets (arkworks/Mina) offer prior art on cross-field arithmetization but may incur per-digit range/copy constraints. Need a concrete cross-characteristic bridge protocol with exact soundness and honest complexity to claim progress.
[IMPORTANT] For coding with relative distance γ and perfectly bound common codeword, probability of missing a nonzero disagreement in t distinct uniformly chosen coded positions is ≤(1−γ)^t; this observation motivates a candidate, it does NOT show one can enforce a cross-field common codeword cheaply. Original Brakedown fieldwise commitments already use coding; those do not provide cross-field witness coherence for free. Avoid claiming lower bound against all such systems.
