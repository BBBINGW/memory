## Mathematical local construction — conditional positive
Let R_q=Z_q[X]/(X^N+1), N power of2, sigma(f(X))=f(X^-1), sigma^2=Id.
Use the SAME underlying RLWE secret s; define orbit secret vector (s,sigma(s)) deterministically, NOT two independent secrets. Ciphertext c=(b,a0,a1) has phase
  phi_s(c)=b-a0*s-a1*sigma(s).
Embed original RLWE (b,a) as (b,a,0). Define free automorphism
  F_sigma(b,a0,a1)=(sigma(b),sigma(a1),sigma(a0)).
Then phi_s(F_sigma(c))=sigma(phi_s(c)) EXACTLY in R_q, with NO Galois switching ciphertext/error. Ciphertext dimension can grow from2 to3 components, but there is no independent extra secret information.

GSW binary selector m∈{0,1}, gadget powers g_j:
 standard RLWE-under-s GSW columns at level j can be represented as C0_j=Enc_s(m*g_j) and C1_j=Enc_s(-m*g_j*s), each a 2-component ciphertext. Embed C0,C1 into three-component orbit space with a1=0. Construct third column C2_j=F_sigma(C1_j), an orbit-format ciphertext supported on b and a1, with phase sigma(-m*g_j*s)= -m*g_j*sigma(s), because binary m is sigma-invariant and scalar g_j is invariant. This is a PUBLIC deterministic transform of existing C1, requires no fresh encrypted selector key, no new encrypted-message assumptions, no persistent extra selector-key rows.
Generalized gadget extprod for c=(b,a0,a1):
   E_m(c)=Sum_j[ digit_j(b)*C0_j + digit_j(a0)*C1_j + digit_j(a1)*C2_j ].
With exact gadget reconstruction, phase E_m(c)=m phi_s(c)+ selector_error, so CMUX(c0,c1;m)=c0+E_m(c1−c0) selects desired phase, including wrapped sigma(c1).
Key storage per binary selector remains original 4*l ring polys (two RLWE columns per level). Operations:
    a1=0 input: 4*l ring polynomial digit-key products, output stays a1=0 because C0,C1 have no a1 mask.
    a1≠0 input: +2*l extra digit-key polynomial products from C2; 6*l total. Need third component decomposition/transform/output only on dual path.
    Sigma(C1) frequency representation is related by permuting inverse roots (complex conjugation for FFT); no independent third key FFT required in exact ring, though actual layout/kernel may incur nonzero transform or gather cost.
The key is not a standard generic 3×3 independent Mat-MGSW (would cost9*l); it is a 3×3 sparse-column matrix with 6*l nonzero polynomial entries and deterministic orbit-related last column. NOTE: ordinary digit-GSW, NOT proved same noise/rounding as scale-based Mat-MGSW T>Q.

Output LWE sample-extraction *can collapse the redundant orbit secret without KS* at constant coefficient: coeff0(a0*s)=a0_0*s0 − sum_{j=1}^{N-1} a0_{N-j}*s_j, coeff0(a1*sigma(s))=sum_j a1_j*s_j. Thus effective ordinary secret-s vector mask is
  A0=(a0_0+a1_0),
  Aj=(a1_j−a0_{N-j}) for j>0,
and LWE body b0. Direct constant-term decryption agrees; however using such extracted LWEs between repeated MPmul steps would require costly LWE-to-RLWE repacking, it is only FREE at terminal output.

## Source-exact support-frontier obstruction from repeated MPmul
Let plaintext-vector length n>=B=2^L and t=number of prefix positions potentially containing a1≠0. Start t=0 under normal RLWE. For shift d=2^i, output j:
 - if j<d, option is F_sigma(c[n−d+j]), introducing a1 if original was a0-only;
 - if j>=d, option is c[j−d].
Full binary CMUX outputs can mix branches *even if encrypted bit is 0*, so a nonzero dual mask may propagate through both branches via random GSW masks. Given prefix support [0,t), the next support upper bound is prefix [0,min(n,t+d)); with generic random masks, support typically equals this prefix, no guaranteed key-compatible cancellation. Thus t increments d at each stage, and after ONE complete MPmul, t=B−1; after r complete repeated MPmul calls, t<=min(n,r(B−1)). Once t=n, ALL subsequent CMUX are full dual.
First MPmul dual operations sum_(i=0)^(L−1) (2^(i+1)−1) =2B−2−L (O(B)), promising compared with nL. But full binary/ternary SAB (source Algorithms2/3) performs h+1 such MPmul calls SEQUENTIALLY on SAME ciphertext list; dual support is NOT reset between them. Over h+1 calls, much or all of nL(h+1) CMUXs become dual. Public multiplication by X^a or XOR/sign CMUX in source does NOT guarantee setting a1 back to zero, so the invariant persists (even more in ternary).
Illustrative shape n=512, B=128, L=7, input sparse key h=39 (h same numeric as source B1 but n512 not claimed source parameter):
 - 40 MPmul calls, 143,360 total GSW CMUX, 135,342 full-dual CMUX (94.4%),
 - eliminated auto-KS operations 40*(B−1)=5080,
 - extra GSW ring-key products at l=1: 2*135342=270684 (plus decomposition, transforms, memory),
 - pure ring product break-even requires one eliminated automorphism KS cost>270684/5080=53.28 ring products. For illustrative full KS gadget length l_KS=3 and 2-poly RLWE output -> ~6 component ring products per automorphism; vastly less than 53.3. This is a CONDITIONAL accounting proxy; actual 2025/686 reduced/approx KS key parameters should be checked before a native performance claim. At n=2048 B128 h39 even worse 454,658 full-dual extprods and threshold179 ring products per eliminated KS.
 - Standalone one MPmul n512,B128: dual247, original127 auto-KS; extra494 ring products, so break-even KS>3.89 ring products. That LOCAL favorable threshold does NOT survive full SAB. Source n, B, h and chosen modulus/security must be fixed jointly before benchmarking; no paper speedup claimed.

## Noise/security analysis and repair search
[NOISE] For selectors, the third column C2=F_sigma(C1) reuses the SAME encryption error e1, and the fresh selector-error contribution is
  err=Σ_j[ d_b,j e0,j + d_a0,j e1,j + d_a1,j sigma(e1,j) ].
It is not valid to treat e1 and sigma(e1) as independent: covariance can increase per-coefficient variance compared to fresh independent column. Conditional norm inequality ||u+v||²<=2(||u||²+||v||²) yields a conservative extra factor2 for aligned components. Adding third-component digit approximation error when l_A=1 (2025/686 FBS1/FBS2) requires fresh detailed DFR analysis. One cannot import 2025/1892 heterogeneous-gadget variance independence formula unchanged; its style of per-stage noise budgeting might be helpful only AFTER full construction cost passes.
[SECURITY] Third column deterministic PUBLIC sigma of existing key C1; so it exposes no independent information beyond the original RGSW, but inherited circular/key-dependent secret encryption assumptions and module-output-message security still need a formal reduction if implemented. Sigma-related module secret (s,sigma(s)) is not two independent RLWE keys; source-key distribution and actual ciphertext outputs require careful model. Output LWE fold shows same underlying N secret coeffs, no additional secret entropy but also does not automatically establish IND-CPA in all settings.
[REPAIR SEARCH A: reset after every MPmul] To keep favorable local O(B) dual frontier, convert dual ring ciphertexts back to ordinary RLWE key s before next MPmul, using KS of a1*sigma(s) into s. At least B−1 potentially dual output ciphertexts at each boundary; source eliminated B−1 automorphism key switches INSIDE prior MPmul. Thus rebuilding standard form with per-output KS eats the savings and adds dual GSW work. This is not a general impossibility of sophisticated batched repacking/reset, but shows simple repair does not solve whole-cost problem.
[REPAIR SEARCH B: terminal extraction] Terminal LWE fold is free and valid, but cannot be used as free ring-input conversion for the subsequent MPmul; the latter expects RLWE encryption of exponentials, so new LWE->RLWE packing is needed and must be accounted for.
[REPAIR SEARCH C: arbitrary selector] Derived third column via sigma(C1) requires sigma(m)=m. Works for binary selectors MPmul and tern-SAB sign CMUX bits. Does NOT directly apply to general rho-SAB monomial-valued selector m=X^u or odd automorphism X^a; could require extra GSW encryptions and kill key-size advantage.
[REPAIR SEARCH D: use scale-based 2025/1711] Could lower cost of extra full-dual rows, but enlarged scale modulus T>>Q/security dimensions, rounding and matrix ciphertext cost would need new proof/implementation. A literal rank2 squared gadget gives up to9 products vs4 rank1, and B014/B015 already found shortcomings of plain substitution. Do not treat as verified repair.
[NOVELTY] Sparse orbit conjugation/selector-column derivation may be a transferable algebraic trick but automorphism key-basis manipulations and module GSW are prior art; no comprehensive similar-method search establishes firstness. No stand-alone new publishable PBS optimization established because complete SAB cost fails.
