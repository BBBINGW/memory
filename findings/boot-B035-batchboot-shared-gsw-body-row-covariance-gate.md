## Mathematical construction
Let R_q=Z_q[X]/(X^N+1), s target RLWE secret, tau:f(X)->f(X^-1), selector m∈{0,1} and gadget g. Normal key consists of D0=Enc_s(-g*m*s), B=Enc_s(g*m). Param inverse key consists I0=Enc_s(-g*m*tau(s)), B'=Enc_s(g*m). Candidate instead samples B ONCE and publicly references it as the second row in BOTH keys, with independently encrypted D0 and I0. This shares the EXACT SAME public ciphertext of the SAME plaintext under SAME s, not B023's insecure use of the SAME mask to encrypt distinct selector messages. Security of shared ciphertext itself is inherited from the assumed allowed original key samples but full joint KDM/circular security remains to be verified under source assumptions.
For input c=(a,b) with exact gadget digits a=g d_a,b=g d_b, and first/second-row fresh encryption errors e_D,e_B,e_I:
  phase_s(d_a D0+d_b B)=m(b-a*s)+d_a e_D+d_b e_B;
  phase_s(tau(d_a) I0+tau(d_b) B)=m*tau(b-a*s)+tau(d_a)e_I+tau(d_b)e_B.
The second identity uses tau(m)=m and tau(a*s)=tau(a)*tau(s), both hold for constant binary selector. No changed secret, no automorphism key switching required for the parametrized product (already source method). Full approximate-gadget rounding and FFT remain source implementation obligations.

## Exact component count, not claimed real complete-key speedup
GLWE dimension1, one nonce and one body gadget level, standard TFHEpp BatchBoot path. 4 direct +3 inverse RGSW=7*2=14 RLWE rows, each row two ring polys: 28 polynomials per radix-4 digit. For the three matching direct/inverse selector messages, eliminate inverse duplicate BODY row =>11 rows/22 polynomials, ideal saved 3/14=21.428571% of the EMP digit-key spectral polynomial payload. ## Decisive negative check: full-output noise covariance is NOT unchanged
Under input c=(a=0,b=g) (constant, hence tau(b)=b), normal and inverse outputs both receive *the same* body-row key error e_B. If a subsequent public linear packing/trace happens to add the two outputs, the resulting error is 2 e_B. In a baseline with independently sampled corresponding body-row encryptions the sum is e_B+e_B' independent. If Var(e_B)=sigma², SHARED variance=4sigma² and separate=2sigma²: 2x increase, exact. 50000 random pairs uniform e,e'∈{-1,0,1} give empirical shared Var2.658165, separate Var1.328926, ratio2.000236. This example is a minimal general two-output linear combination, NOT yet an exact proven path of USENIX Alg2/Alg6; some real path restrictions may cancel covariance. It nevertheless falsifies the stronger assumption that public reuse automatically preserves ANY additive/independence-based noise bound or total DFR. Authors Appendix C.2 uses additive variance and full BatchBoot repacks multiple outputs; full joint selector-error incidence + repacking coefficients must be audited before performance/security claim.
The marginal key rows remain proper RLWE ciphertexts and can be reused across independent operations, but covariance across paths is real. Source PDF Table1 already writes shared semantic row RLWE'_s(m), so deduplicating randomized *storage* is natural algebraic/engineering reuse rather than a new crypto algorithm; original authors artifact uninspected, and no claim of global novelty.
