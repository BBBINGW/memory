## Exact symmetry lemma [DERIVATION, PROOF]
Let periodic extension period T, original interval [-a,a] with a=T/4, bridge [a,T-a]. Suppose real f(-x)+f(x)=2c on [-a,a]. Let g=f-c, so g(-x)=-g(x) and g^(j)(-a)=(-1)^(j+1)g^(j)(a). Form the unique Hermite bridge H of degree <=2k-1 matching g and its first k-1 derivatives at x=a and x=T-a to those at x=a and x=-a, respectively. Polynomial Hstar(x)=-H(T-x) satisfies the exact SAME Hermite endpoint derivative constraints by reflection, hence Hstar=H by uniqueness. Periodic extension G that equals g on [-a,a] and H on [a,T-a] obeys G(-x)=-G(x) mod T. Its mean and ALL cosine Fourier coefficients vanish: a_n(G)=0 for all n>=0. So original f period-extended equals c + G and all positive cosine harmonics vanish exactly, while constant harmonic=c (source scales the target by 1/2, so c_src=c/2).
In particular sigmoid(x)=1/(1+exp(-x)) satisfies sigmoid(-x)=1-sigmoid(x), c=1/2, so source scaled target mean1/4; all nonzero harmonic coeffs are PURE IMAGINARY ck=a_k-i*b_k=-i*b_k in exact arithmetic. Non-trivial functions with affine-odd symmetry automatically satisfy parity in symmetric source FE; the fact is elementary, does NOT invent a novel FBS scheme.

The author actual EvalFEFuncBootstrap source already executes exactly ONE polynomial evaluator cc->EvalPoly for both sigmoid and general GeLU, then one Conjugate; clipping near-zero cosine coefficients DOES NOT reduce degree34 or the number of ciphertext multiplications/rotations/levels by default. This source check is decisive against ungrounded speedup.
2. A general affine-even trick on GeLU: the author's tanh argument is odd, tanh is odd, so GeLU(-x)=GeLU(x)-x and E(x)=GeLU(x)-x/2 is even. But subtracting x/2 is NOT an innocuous public constant; HalfBTS output is y=σ(m)+I with UNKNOWN INTEGER I. Every correctly handled Fourier extension is periodic: z=exp(2pi i y)=exp(2pi i σ(m)). If one evaluates the periodic even E(y) and naively adds y/2, output includes spurious I/2. Counterexample x=.2, two legitimate integer lifts I=0 and I=1 have identical z but direct affine term differs exactly .5, cannot be publicly corrected without extracting unknown carry I. Therefore free GeLU-even conversion FAILS the actual HalfBTS FBS interface; would require an additional modulus/carry correction/boot computation with noise/cost. Authors' original periodic Fourier evaluation has no such flaw.
3. Trimming coefficients to exact pure-imag for sigmoid changes only public plaintext weights; original EvalPoly still processes same powers z^k. Marginal noise of input exp approx, EvalPoly and Re extraction unchanged at kernel counting; cannot claim novel 2x. Security/key distribution unaffected by PUBLIC coefficient cleanup but complete CKKS 2^-128 DFR not established.
4. GeLU and exp need both cosine and sine channels because source coefficients reflect real non-even/non-odd f; no blanket function-class optimization.
5. This source represents a main EUROCRYPT26 development already in OpenFHE, so avoid mistakenly presenting authors' own parity property as new 2026 research result.
