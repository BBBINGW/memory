## Necessary-and-sufficient algebraic criterion
Work over R=F_q[X]/(X^N+1), N a power of2, q odd and q relatively prime to d, d=N/n a power of2. Normalized trace to subring R'=F_q[X^d]/((X^d)^n+1) is projection P_d(sum a_i X^i)=sum_(i divisible by d) a_i X^i. The R'-module R is free of rank d with basis 1,X,...,X^(d−1). The trace is R'-linear but not R-linear.
THEOREM: P_d(Ax)=A P_d(x) for ALL x in R if and only if A is in R'. Proof: necessity set x=1 to obtain A=P_d(A). Sufficiency follows by R'-linearity.
Thus a ciphertext external product whose ideal encrypted plaintext factor A lies in target subring can commute with trace in PLAINTEXT algebra, but an off-subring factor CANNOT. Source Algorithm5 public replication temp(X)=sum_(r=0)^(d−1) X^r is outside R' whenever d>1. Consequently the exact source PRCA cannot unconditionally postpone its trace through temp; even if a later monomial selector is in subring, temp is already an obstruction.

## Possible repair and exact information rank gate
Polyphase decomposition x=sum_(r=0)^(d−1) X^r x_r with each x_r in R'. A purported trace-lazy representation retaining only x0=P_d(x) loses off-subring cosets. If next-step plaintext selector may multiply by any monomial X^k for k in0..d−1, the full vector of projected outputs (P_d(X^k x))_k recovers ALL d coset components, up to signs and position permutations. The linear map R -> (R')^d is an N×N SIGNED PERMUTATION matrix, hence rank N and M^T M=I in coefficient representation. Independently checked 12/12 (N8,16,32,64,d2,4,8) test settings by constructing integer coefficient matrices, 100% rank N and orthogonality.
This is a sharp linear information lower bound ONLY for unrestricted d shift residues and representations that compress to R'-coefficient data. The actual LFBS Enc(m) shift set may use a strict subset (then rank budget is corresponding coset count), so do not misapply d as a universal LFBS lower bound. Also, a single standard RLWE_N ciphertext ALREADY stores N coefficients: 'd channels' refers to algebraic R'-components, not d independent RLWE_N ciphertexts. A novel tensor/multiring representation could carry all needed coset data with distinct operator costs, but no end-to-end construction or gain has been shown.
