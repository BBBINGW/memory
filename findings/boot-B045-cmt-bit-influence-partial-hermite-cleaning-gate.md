## [DERIVATION] Exact bit-influence certificate
Let b in {0,1}^k, perturbed x_i=b_i+e_i, |e_i|<=delta_i. Ideal BMT Kronecker computation is multilinear extension F(x)=sum_{v in {0,1}^k} f(v) prod_i(x_i if v_i=1 else 1−x_i), so F(b)=f(b). Public discrete influence D_i=max_{v:v_i=0}|f(v+2^i)−f(v)|. Telescoping coordinates in order i=0..k−1: each i-th partial derivative is a multilinear extension of an edge-difference table bounded by D_i. For preceding possibly out-of-[0,1] coordinates |1−x_j|+|x_j| <=1+2 delta_j, hence the deterministic valid bound for real slot values is |F(b+e)−f(b)| <= sum_i D_i delta_i prod_{j<i}(1+2delta_j). No independence or randomness assumption; this bounds only BMT ideal input-noise propagation, not CKKS evaluator rounding and key-switching errors. At Boolean endpoints Gid(b+e)−b has no linear term and |.|<=3epsilon^2+2epsilon^3. For epsilon=.01, cleaned bound .000302 and uncleaned .01.
