## Concrete scalar construction under IDEAL secure 2PC [DERIVATION]

Trusted KeyGen, already holding full s, computes m=||s||², Shamir-shares m independently from s with a random degree-(T−1) polynomial. For scalar secret dimension n and coefficient bound B, possible integer m∈[0,nB²], so there are at most nB²+1 candidate public tables, polynomial if n and B poly κ. For each possible m with Bpub²>m, publicly precompute a discrete-Gaussian inverse CDF for target width σ_m=σ0 sqrt(Bpub²−m), truncating support S to ±H and choosing b-bit cumulative thresholds. Crucially, **public family is identical regardless of which actual secret was sampled**.

Per fresh sid and chosen EXACT T=2 active parties:
1. Invoke a confidential, secure authenticated 2PC with Shamir input shares m_i and fresh private jointly randomized coins U uniform in [0,2^b). Recombine m and select the corresponding PUBLIC table ONLY INSIDE the functionality; do not disclose U, m or the selected table index to either party or Server.
2. Let quantized inverse CDF output scalar ζ∈S. Draw fresh uniform w1∈F_q and output weighted shares w1 and w2=ζ−w1 mod q to the two active parties. These are the only outputs of the ideal sampler. Server receives neither ζ nor m.
3. Parties use modified original replies pd_i=λ_i(a^T s_i)+w_i+PRF(seed_i,sid) for active i. This has the same law, conditional on ζ, as original λ_i(a^T s_i+ζ_i)+m_i when original ζ_i are fresh **degree-1 Shamir shares**: since interpolation weights λ_i are nonzero for distinct party IDs over a field, w1=λ1 ζ1 is UNIFORM in F_q as the Shamir slope varies, and w2=ζ−w1, so the pair distribution is IDENTICAL conditioned on ζ. All PRF seeds remain unrelated; no public per-party pad transport as in CGS34.
4. For N=3, all THREE authorized active PAIRS {1,2},{1,3},{2,3} work, each with its own λ values. This test does NOT handle |act|>2 or equivocal same-sid cross-set queries. Source uses fresh sid once per ODec, but a real adaptive-corruption simulator MUST still be rebuilt for the new 2PC transcript, party abort and chosen active-set processing.
5. This is an **ideal functionality** with computational 2PC security assumptions; no claim that the source's standard LWE+PRF theorem directly implies privacy of the extra online 2PC. ## Statistical precision theorem [DERIVED]

Let f_m be the ORIGINAL discrete Gaussian mass, and let S={−H,...,H} contain tail mass τ_m outside. Truncate+renormalize to f_m^S (TV(f_m,f_m^S)=τ_m). Form the truncated CDF F_m(j)=Σ_{x≤j} f_m^S(x), and integers θ_j=floor(2^b F_m(j)), forcing the last θ=2^b. For private U uniform integers 0...2^b−1, set sample to first x_j for which U<θ_j. Then quantized PMF q_m(x_j)=(θ_j−θ_{j−1})/2^b.
Each CDF θ_j/2^b differs from F_m(j) by <2^(−b), so the total variation is conservatively
TV(q_m,f_m^S)≤|S|/2^b.
Therefore
```
TV(q_m,f_m) ≤ τ_m + |S|·2^(−b).
```
For at most LDec adaptively chosen sessions with uniformly bounded tails, a straightforward conditional hybrid has total ≤LDec·max_m(τ_m+|S|2^(−b)), as long as fresh private U and fresh weighted sharing are independent from all prior view conditioned on the secret. Sufficient (not optimal) choice for total ≤2^(−κ) is τ_m≤2^(−κ−1)/LDec and b≥κ+log2(|S|)+log2(LDec)+1. This requires tail cutoff H large enough from source Lemma3.11 and polynomial parameters.

This is a *real positive* asymptotic conditional sampler interface for finite public PARAMETER FAMILY indexed privately by m, not a magic noninteractive Gaussian PRSS. It applies only to SCALAR norm-square family, NOT native module-wide correlated discrete Gaussian with potentially exponentially many possible covariance matrices.

## Scientific assessment and precise tradeoff

**Positive technical result (conditional):** A secure ONLINE MPC oracle that internally chooses a public table from a POLYNOMIAL family based on **secret Shamir norm**, uses PRIVATE random coins and outputs fresh random weighted shares can replace scalar Algorithm6's offline length-LDec list with one long-term norm share per party; its output distribution/statistical deviation can be rigorously bounded. This avoids **both** direct publishing of secret-dependent tables (CGS38) and applying nonlinear quantile operations separately to Shamir shares (CGS21/36), by offloading them to full secure MPC. For EXACT T=2 active sets, weighted additive shares faithfully match the original padded Shamir reply distribution.

**Necessary new costs/limitations:** (i) interaction: more than original two online rounds, at least a real OT-based secure 2PC; (ii) per-sid private comparison/mux circuit with size O(C_m |S| b) under naive public-table family, and possible online bandwidth proportional to circuit or number of OT calls, NOT benchmarked; (iii) source privacy theorem for adversarially observed all PartDec + NEW online 2PC transcript needs composition and proof, may require malicious security/abort; (iv) arbitrary **|act|≥T**, general T and module Gaussian with SECRET full covariance not handled; (v) source standard scalar known-norm route §5 ALREADY avoids pads, so scientific novelty/advantage is likely LOW vs existing theorem. There is NO claim to have solved original module-LWE O(LDec) problem under source online or assumption goals.

**Important comparison:** Standard MPC feasibility under relaxation is expected/folklore. There may be no publishable contribution absent a clever structure reducing memory, OT cost or respecting original low-round interface. Avoid pretending generic 2PC produces new cryptography.
