## Rank for NEXT SCREEN (not proven publishability)

1. **Agent reliable multi-step tool collaboration (A1): conditional P0.** Priority because single-machine, deterministic tool/event fault injections plus accessible Agent benchmarks can check concrete invariants cheaply; user has first-hand artifact-provenance/agent workflow context. *Not* a generic 'agents need reliability' or 'add transactions' idea. Prior art is exceptionally strong; proposal is to screen exact **intersection** of multi-agent concurrent consistency, revocable effect-time delegated authorization, and heterogeneous/opaque/irreversible external effects. Start with prior-art/no-go boundary, NOT code. The full original HTML [CoAgent arXiv:2606.15376](https://arxiv.org/html/2606.15376) §3–6 builds MTPO serializability with footprint-declared, registered undoable toolcalls; [Cordon arXiv:2606.17573](https://arxiv.org/html/2606.17573) §3–6 implements semantic transactions, shadow state, effect outbox, authority and lineage, but §6.5 openly limits complete coverage to mediated observable effects; opaque external plugins/out-of-band effects are not guaranteed. Additional prior-art [DelAct IWQoS2026](https://ieeexplore.ieee.org/abstract/document/11661202/) has replayable boundary/commit IDs/idempotent tool effects; [DelegateGuard arXiv:2610.16005](https://arxiv.org/abs/2610.16005) has purpose-bound revocable capabilities; [ResidualAuth arXiv:2609.08062](https://arxiv.org/abs/2609.08062) has authorization-state lower bounds; [AgentRx Microsoft Mar2026](https://www.microsoft.com/en-us/research/blog/systematic-debugging-for-ai-agents-introducing-the-agentrx-framework/) covers failure root-cause localization, so these are NOT new primitives. Strongly relevant ICML2026 empirical [Towards a Science of AI Agent Reliability](https://proceedings.mlr.press/v306/rabanser26a.html), [Measuring Agents in Production](https://proceedings.mlr.press/v306/pan26a.html); [AppWorld-UL ICML2026](https://proceedings.mlr.press/v306/chen26eg.html), [AgentSuite](https://proceedings.mlr.press/v306/suh26a.html), [SciAgentGym](https://proceedings.mlr.press/v306/shen26aa.html) provide existing test environments. **H-A1 to falsify:** Is there a *specific* supported tool API regime where existing CoAgent/Cordon/DelAct/DelegateGuard guarantees individually miss a joint safety/liveness property, while the system exposes sufficient primitive observation/idempotency/authorization metadata for a nontrivial, provable improvement? An opaque irreversible effect with NO status/receipt is an information-theoretic impossibility regime, not an unsolved construction. Need exact semantics and counter-prior-art. **NEXT TEST:** Build source-anchored baseline assumption/invariant table for four systems; choose ONE two-agent, two-tool fault/revocation schedule and determine if a claimed hole survives the strongest baseline; if fully covered or unobservable effects make correction impossible, **KILL A1 promptly**.
