## Exactly ONE primary falsifiable hypothesis
[HYPOTHESIS H-B4, falsified] Given He–Vershynin–Zhu's event-level pure epsilon-DP online synthetic data algorithm on [0,1]^d, allowing the second private-data arrival to be chosen as a function of the first public synthetic release *necessarily invalidates its full-transcript epsilon-DP guarantee*, even if the adaptive input pairs remain event-level neighbors (differ in at most one round). This purported generic feedback/privacy mismatch would demand a new privacy primitive.

Cheapest decisive test: original-source prior-art theorem comparison (He Def.2.1–2.2, §2.2, Theorem1.1 and Proposition4.1; Denisov et al. Prop.2.1; FORC2026 Def.4–5/§1.3) plus ONE two-round adaptive neighboring-transcript instantiation. This is not a test of utility, user-level privacy, or large-model recursive collapse.

## ONE minimal two-round test [DERIVATION / source theorem application]
- Fix bounded stream domain [0,1]. Challenge side b∈{L,R}. At round 1, adversary chooses (x_1^L,x_1^R)=(0,1). Mechanism outputs y_1, a synthetic dataset (He may return a complex object).
- At round 2, adversary chooses SAME x_2^L=x_2^R=g(y_1)∈{0,1} where g is any public measurable function of observed first release. This is legitimate adaptivity: although actual g(y_1) distributions differ between challenge worlds, the two submitted alternatives are equal IN EACH interactive execution, and the chosen pair of candidate streams differs in only the round-1 position. The adversary's view includes both messages and outputs.
- Because He has pure epsilon-DP with identical event-level neighbor relation, Denisov et al. Proposition 2.1 already entails View_L ~=_(epsilon,0) View_R for this valid two-round adversary. Extend to each finite prefix, and standard cylinder-set reasoning supports infinite output privacy for the same fixed epsilon under usual measurable sequence assumptions. This does not cover user-level neighbors where the same user contributes at both t=1 and t=2.
- Transparent illustrative surrogate (NOT a claim about He's exact mechanism): M at round1 releases Z=x_1+Lap(1/epsilon), at round2 releases (Z,Z+x_2), where x_2=g(Z) is selected from the first release. For b=0 vs 1, f_0(z)/f_1(z) = exp(epsilon*(|z-1|-|z|))∈[e^-epsilon,e^epsilon]; entire view (Z,Z+g(Z)) is postprocessing and obeys epsilon-DP. This independently verifies the logic of one explicit two-round transcript; the broad transfer proposition remains existing prior art.
- A feedback rule that permits x_2^L != x_2^R in addition to x_1^L != x_1^R would be a TWO-RECORD neighboring change and falls OUTSIDE He event-level protection, not a counterexample to its theorem. Analogously, changing whole repeated-user trajectories is a different privacy promise.

## Result and research boundary
[NEGATIVE] H-B4 is FALSE: the generic claim that feedback dependence alone breaks He pure epsilon-DP is directly negated by pre-existing NeurIPS2022 Proposition2.1; FORC2026 already explicitly points this out. This is NOT an original new mechanism, proof, exploit, or novelty.
[UNCLEAR] He Theorem1.1 expected W1 accuracy applies pointwise to every deterministic precommitted input stream. Adaptive x_{t+1}=g(Y_t) can correlate future inputs with the release noise, so the original fixed-data expectation proof cannot automatically be conditioned as written. HOWEVER no He-specific adaptive utility counterexample, lower bound, or repair is proven this round, and the FORC2026 Theorem7–8 separation is for its own correlated-vector task, NOT necessarily He's W1 workload.
[UNCLEAR] New real-data distributions, multiple silos, public or hidden target features, user-level whole trajectories, local DP, communication limits, rare tail/no-collapse guarantees remain separate questions. None is an established novelty claim.
Decision: KILL generic adaptive-privacy-loss rationale; keep feedback-adaptive Wasserstein UTILITY as one possible next source-level boundary pending PI choice.
