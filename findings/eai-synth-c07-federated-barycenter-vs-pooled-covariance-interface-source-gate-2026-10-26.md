## ONE minimal derivation (and no other technical test)
Let d>=2, a>0, sigma>0, e1 standard basis. Two sites have equal weights 1/2 and private real distributions:
 Q1=N(-a e1,sigma² I_d), Q2=N(+a e1,sigma² I_d).
Pooled real population (task target assumed explicitly) is
 P_pool=0.5 Q1+0.5 Q2;
 E[X]=0,
 Sigma_pool=E[Cov(X|site)]+Cov(E[X|site])
 =sigma² I_d +a² e1 e1^T.
As Q1 and Q2 are translated versions of N(0,sigma²I), optimal transport from Q1 to Q2 is translation 2a e1. Two-site equal-weight 2-Wasserstein barycenter is the geodesic MIDPOINT
 P_bar=N(0,sigma² I_d), Sigma_bar=sigma² I_d.
Therefore Sigma_pool−Sigma_bar=a²e1e1^T, spectral norm a², Frobenius norm a². At a=sigma=1, true pooled first-direction variance=2, barycenter variance=1, i.e. 50% underestimate relative to true pooled variance. This persists with exact OT and infinite within-silo data: it is a target semantics / missing BETWEEN-SILO VARIANCE effect, not numerical barycenter approximation or DP noise.
Even stronger: for every a>0, P_bar is IDENTICALLY N(0,sigma²I) while Sigma_pool varies with a. A function of barycenter alone cannot recover sigma²+a² as a function of a for two different a. This establishes H-C07 false for POOL-MIXTURE targets and barycenter-only transcript. Does not establish the same conclusion if transcript includes individual silo local means, full Qk, OT couplings, or the intended target IS barycenter.
Standard exact repair if target really pooled mixture and each silo provides its FIRST and SECOND moments:
 mu_global=sum lambda_k mu_k;
 Sigma_pool=sum lambda_k Sigma_k +sum lambda_k(mu_k-mu_global)(mu_k-mu_global)^T
 = sum lambda_k (Sigma_k+mu_k mu_k^T)−mu_global mu_global^T.
This is law-of-total-covariance, NOT a new construction. Central DP release of moments requires an adjacent-record model and bounded feature norms; secure aggregation/MPC does not automatically give DP; C04 and ALT2026 covariance estimation are strong novelty killers.
