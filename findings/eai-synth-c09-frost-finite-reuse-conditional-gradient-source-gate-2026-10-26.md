## ONE decisive exact finite-data calculation [DERIVATION]
Draw D=(X_1,...,X_n) iid once from Rademacher on {-1,+1}; n>=2 fixed. Use scalar quadratic sample loss `ell(theta,x)=1/2*(theta−x)^2` and population loss `L_P(theta)=1/2*(theta²+1)`; pop gradient `gbar(theta)=theta`. Freeze all model parameters theta_t=0 (valid S=0 and L=1); at each time t draw index I_t IID uniformly from {1,...,n} independently of indices given D (one-record real minibatch sampled WITH replacement from fixed D). Observed gradient `R_t=−X_{I_t}` while `gbar_t=0`. Let sample mean `m_D=n^-1 sum_i X_i`; if the pre-step history includes fixed accessible training data D, then
 E[R_t−gbar_t|D,F_{t−1}]=−m_D,
 nonzero with positive probability. Even if data initially hidden from the filtration, repeated observed gradients reveal data information; source Eq18 does not simply follow from uniform index sampling. Conditionally on D, the mini-batch gradient is unbiased for EMPIRICAL gradient `g_D=−m_D`, NOT necessarily population gradient zero.
FROST Eq20 normalized EMA weights `w_{t,k}=(1−beta) beta^{t−k}/(1−beta^t)`, sum w=1, `Rhat_t=sum w_{t,k}R_k`. Condition on D:
 E[Rhat_t|D]=−m_D,
 Var(Rhat_t|D)=(1−m_D²) sum_k w²
with distinct I_t independent conditional D. Since E_D[m_D²]=1/n and E_D[1−m_D²]=1−1/n,
 exact population MSE:
 E[(Rhat_t−0)²]=1/n+(1−1/n) A_t,
 A_t=sum_k w²=((1−beta)/(1+beta))*((1+beta^t)/(1−beta^t)).
As t→∞ for fixed 0<=beta<1,
 `lim E[Rhat_t²]=1/n+(1−1/n)(1−beta)/(1+beta)`.
As beta→1 after t large, the **data sampling error floor** 1/n remains. EMA smooths repeated stochastic index noise but cannot create fresh population information.
One numeric anchor n=10, beta=.99, t=1000: beta^t≈4.317e-5, A_t≈0.00502556, true MSE≈0.104523. Using source Eq19 with L=1, S=0, nu_R²=1 (indeed E[(R−gbar)²|history]=1), if someone INCORRECTLY assumes Eq18, its RHS is `2*((1−beta)/(1+beta)) / (1−beta^t)^2≈0.010051`, strictly below actual 0.104523. This numerical mismatch only shows applying a CONDITIONAL theorem OUTSIDE hypotheses is wrong. There is NO counterexample to Eq19 as actually stated and no evidence the author's real experiment used this theorem invalidly.
More explicitly, for fixed theta, empirical-gradient drift term is `g_D−g_P=−m_D`. A correct reuse analysis can decompose `Rhat−g_P=(Rhat−g_D)+(g_D−g_P)`; the first is EMA sampling noise conditioned on D and the second is training-sample generalization error. For adaptive theta_t depending on D, controlling the latter needs algorithmic stability/DP, uniform convergence, sample splitting or other source-supported assumptions. This standard decomposition itself is NOT new.
