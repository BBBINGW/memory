## ONE constructive falsifier / costs [DERIVATION]
Assume explicit source contract: both A.calendar.reserve(u) and B.rooms.book(u) access the same globally keyed unique slot u, only one active reservation per u, and ALL such writes are mediated by a single transactional store. Let S_t contain ActiveReservations(slot,owner,active). The parameterized relational predicate Q_u(S_t)=EXISTS r: (r.slot=u and r.active) returns one Boolean. Maintain this predicate by an indexed key or an incremental COUNT per key; insert/cancel/modify sends deltas to exactly affected views. Invoke B simulator with current request and e.g. JSON {slot:u, occupied:Q_u(S_t)}, NOT T historical API events. For constant-width slot IDs, context contributed by state view is constant; with growing key domain |U|, key encoding O(log|U|) bits and Boolean 1 bit; optional version field may use O(log T) bits. Back-end maintenance is NOT constant-time/space by this argument. If full application history serializes T bounded-size events, naive history context is Theta(T) tokens vs compact state independent of T in this restricted query.
CORRECTNESS: B must not simply trust an LLM decision made on a potentially stale snapshot. Execute the check-and-insert of u as ONE serializable transaction, abort/retry on conflicts, so any committed schedule is equivalent to a serial order and the shared single-active-reservation invariant holds (assuming business constraint encoded and no unmediated writes). Under a previous A reserve(u), Q_u=1 yields conflict for B; absent that write, Q_u=0 allows B to commit. This resolves the exact C12 two-world shared-slot witness with standard database methods and no new causal projection primitive. Strong ACID semantics are from the transaction layer, not Noria/DBSP on their own.
Source comparison kills novelty: Noria already handles query-specific partial state and on-demand readset reconstruction; DBToaster/DBSP compile incremental views; SSI already checks concurrent dependencies. An event log and keyed materialized projection are textbook composition. This single compact example is sufficient to FALSIFY necessity of a novel method in the specified class; it is NOT a claim every natural-language API schema can be compiled or every general temporal query has constant-sized witness.
