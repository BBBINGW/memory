## Single decisive semantic reduction [DERIVATION]
Fix one resource ID u (finite alphabet abstraction) and denote two public action labels: a = A.reserve(u), b = B.book(u); use language membership for sequences consisting entirely of successful calls. This is an intentionally restricted deterministic sequential ACCEPTED/REJECTED abstraction, NOT recovery of full API response bodies and NOT concurrent transactions.

Independent world W_ind: A LTS has p0 --a--> p1, B LTS has q0 --b--> q0 with Σ_A={a}, Σ_B={b}. Hence a,b,ab are enabled. The local product test for ab succeeds iff both projection a and projection b are locally admitted.

Hidden shared-inventory world W_shared: A LTS still has p0 --a--> p1. B-associated semantic LTS has alphabet Σ_B={a,b}, state q0 --a-->q1 and q0 --b-->q0, with no b from q1; A alphabet Σ_A={a}. The event **a participates in B's abstract state transition even though a is only A's public API call**. Product accepts a and b separately, but rejects ab because after a the B-associated state is q1, where b disabled. Thus L(W_ind) contains ab while L(W_shared) excludes it. Note this is an EFFECTIVE state-machine factorization, not proof that actual app B physically sees A's API call or that the world really has exactly those components.

For initial Ω={{a},{b}}, composing separate observed one-letter traces makes ab spuriously accepted when global Teacher says ab is rejected. That is precisely a GLOBAL negative counterexample to the current alphabet distribution. CoalA Algorithm 1 + Lemma 5.1 and §4 refinement allows an overlapping or merged alphabet containing {a,b}; its Theorem 5.3 already covers this model class under ideal oracle assumptions. Therefore a novel 'discover unknown cross-app synchronized action alphabets by counterexample/refinement' mechanism is NOT necessary in the specified class.

Subtle boundary: This shows behavioral ability to model a→b inhibition, not identification of physical CAUSAL edges or true independent service boundaries; Remark 5.4 explicitly limits physical component recovery. General data-valued equality without finite abstraction, async out-of-order events, hidden time-delays, irreversible side effects, stochastic outputs and multi-record transactions are outside this particular reduction. CoalA's ideal equivalence oracle is stronger than practical fixed-budget validation.
