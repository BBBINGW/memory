## Exact arithmetic test and conditional construction

Let `R=N/2` and `G^+=<σ_5>` cyclic order R in automorphism group of `R_Q=Z_Q[X]/(X^N+1)`; `G^-=σ_{-1} G^+`. Precompute `B_b=KGen(σ_{5^{2^b}})` for `b=0,...,log2 R−1`, plus one conjugation master; `K_0=Enc_s(P s)`. For i∈[1,R−1], define `lowbit(i)=2^{v_2(i)}`, `parent(i)=i−lowbit(i)`, derive via source's encrypted-KEY update abstraction:
```
K_i   = KeySwitch_{σ_{5^{lowbit(i)}}(s) -> s}
         ( Auto_{5^{lowbit(i)}}(K_parent(i)) );
```
The corresponding master public evalkey `B_{log2 lowbit(i)}` effects that key switch. Message under final s is `P*σ_{5^i}(s)`, by automorphism composition. For negative coset first use master conjugation to derive `K^-_0=Enc_s(P σ_{-1}(s))`, then same powers on negative branch; `σ_{5^a}σ_{-5^b}=σ_{-5^{a+b}}`. This is the **same public-key-update technique** Park already uses, but the schedule and jump-key set differ. Existing source keygen formula with `P P'` master moduli must be verified for every jump index and gadget rank before declaring complete RNS correctness/security.
