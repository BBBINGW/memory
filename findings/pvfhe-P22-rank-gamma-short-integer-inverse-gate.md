## Positive lemma 1: Gamma_rank has polynomial t and useful sampler [DERIVATION]

Let each legal challenge C_i be a binary xi×kappa matrix, B(S) the horizontal concatenation of blocks in challenge-set S. Define Gamma_rank(S): rank_F2 B(S)=xi. Original CMNW coordinate-wise star implies this (source Lemma1 has integer H, hence B H=I mod2).

For useful c in U_Gamma_rank(S), the new block necessarily INCREASES the column rank: if columns of c are already in span_F2 B(S), c cannot be pivotal for any Gamma_rank completion containing S. Every useful addition increases rank by >=1, so
   **t_Gamma_rank <= xi.**
Conversely all rank-increasing c are useful: a hyperplane can contain span B(S) and exclude one column of c; challenge blocks with unit-vector columns can generate that hyperplane, making c pivotal. Consequently U_Gamma_rank(S) equals rank-increasing blocks. Sampling uniform random binary xi×kappa block hits this set with probability >=1-2^(−kappa) when rank<xi, yielding expected-constant rejection sampling. Gamma theorem combinatorics are GOOD, but source's lattice extractor is NOT implied.

## Positive lemma 2: Gamma_Z has polynomial t [NEW GENERAL DERIVATION]

Let L(S) be the integer lattice generated by all binary block columns B(S), and Gamma_Z={S:L(S)=Z^xi}. Original coordinate-wise star implies Gamma_Z since source BH=I_Z, so Gamma_Z is a valid enlargement at the level of admissible challenge sets. If c is useful, L(S∪{c}) MUST strictly contain L(S); if it is unchanged, adding c can never be pivotal for ANY completion containing S.

Along a useful sequence, rational lattice rank rises at most xi times. At the beginning of each rank-h stage choose h independent binary columns, whose integer span L0 lies in current L. Let L_sat=(span_Q L)∩Z^xi and d=[L_sat:L]; the index is <=[L_sat:L0]=gcd of all h×h minors of the h-column matrix, <=h^(h/2) by a nonzero minor plus Hadamard. Every strict same-rank lattice enlargement decreases positive integer index d by a factor >=2. Thus at most (h/2)log2 h same-rank useful steps occur at rank h. Summing rank increases and same-rank steps gives
    **t_Gamma_Z <= xi + SUM_(h=1)^xi floor((h/2)log2 h) = O(xi^2 log xi).**
This is a real positive result: enlarging Gamma can eliminate P21's t-combinatorial exponential lower bound. HOWEVER efficient uniform sampling U_Gamma_Z and SHORT H remain UNPROVED.

## Decisive falsifier 2: Gamma_Z does not guarantee short integer H [PROVED]

Let S be the strict upper-shift n×n integer matrix and let
    B_n = I_n + S + S^3.
This is binary, upper-unitriangular, det=1, belongs Gamma_Z and Gamma_rank. Its ONLY integer right inverse is H=B_n^−1. Let a_k be coefficient of S^k in (I+S+S^3)^−1. Then a0=1,a1=−1,a2=1 and a_k=−a_(k−1)−a_(k−3). For b_k=(−1)^k a_k, b0=b1=b2=1 and b_k=b_(k−1)+b_(k−3), which is nondecreasing and b_k>=2b_(k−3). Hence
    **max_ij |H_ij| >= b_(n−1) >= 2^floor((n−1)/3)**  for EVERY n.
When n=xi=rκ, group its n binary columns into r legal xi×κ challenge blocks; its inverse remains unique and exponentially large. This demonstrates that an unqualified Gamma_Z Lemma3 norm-transfer fails: small 0/1 challenges + exact integer invertibility do not force small integer reconstruction coefficients.
