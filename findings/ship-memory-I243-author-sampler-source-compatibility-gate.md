## Exact conditional distribution theorem [DERIVED; tested]

Set `N=16384,h=31,w=N/(2h)`. Half-open source windows `W_j=[(j−1/2)N/h,(j+1/2)N/h)` modulo N partition the integer coefficient indices exactly: 15 cells size528,16 cells size529. Let `U` be uniformly chosen support of size h among all C(N,h) combinations, and `E={|U∩W_j|=1 for every j=0..h−1}`. Then for any tuple `x=(x_0,..,x_(h-1))∈W_0×···×W_(h−1)`,
```
Pr[(U∩W_j)={x_j} for all j | E] = 1 / prod_j |W_j|
                                 = prod_j [1/|W_j|].
```
This is an **exact factorization**: under *the CONDITIONAL-UNIFORM prior* `U|E`, each window's selected location is independent and uniform. Event probability
```
 Pr(E) = prod_j |W_j| / C(N,h)
       = 528^15 * 529^16 / C(16384,31)
       ≈ 4.956062327810504e−13 = 2^(−40.8758709025).
```
(The prior's 40.8759-bit event exponent is NOT attacker log2-work difference.) Consequently, I242's one-independent-uniform-position-per-disjoint-window Monte Carlo is **exactly the natural conditional-uniform secret-distribution model** for N2^14/h31, not arbitrary. But unless the original author implementation samples `U|E` (or equivalent), this does **NOT** establish actual authors' secret distribution. Even if location support factorizes, fixed/independent ± sign choice and additional constraints also must be checked. **N8192/h31 source windows overlap because w175 > N/(2h)**: no independence factorization from this theorem for that parameter.
