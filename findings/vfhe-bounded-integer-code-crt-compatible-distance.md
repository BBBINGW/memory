## One primary falsifiable hypothesis and minimum test
[HYPOTHESIS — PASS algebraically] The failure of external F_P Reed–Solomon canonical-representative reduction in I65 can be circumvented at the **encoding** layer for bounded Boolean inputs z∈{0,1}^m by choosing a small nonnegative integer coefficient generator G∈{0,1}^{M×m}, M=4m: its symbols never wrap when reduced modulo any CRT prime p_i>m and, for some choice of G, distinct Boolean messages have Hamming distance ≥M/8 simultaneously over integers and in all such CRT fields.
[FALSIFIER] Either an honest encoded integer y=Gz exceeds some required p_i and loses consistent canonical representation, OR for every possible G there exist distinct Boolean messages z,z' whose encoded difference has fewer than M/8 nonzeros over the target primes, breaking constant-distance amplification.
[CHEAPEST DECISIVE TEST] Analytic uniform bound on integer magnitudes and probabilistic-method distance lemma; exact high-precision arithmetic evaluation of union-bound exponent for c=4 and δ=1/8. No dense random-matrix construction, no parameter sweep, no FHE or PIOP implementation.

## Formal theorem — restricted Boolean input code
Let m be a positive integer, M=4m. Choose independent Bernoulli(1/2) entries G_rj∈{0,1}. Define integer code E_Z(z)=Gz∈Z^M for z∈{0,1}^m.

(A) **No-wrap cross-prime compatibility.** For all messages, 0≤(E_Z(z))_r≤m. If every CRT prime p_i>m, the same canonical integer output in [0,m] is obtained by evaluating Gz over each F_(p_i) and mapping its prime-subfield value back to integers. Thus E_Z(z) mod p_i=E_(F_pi)(z mod p_i), with no ambiguity from canonical lifts. For a digit alphabet {0,...,β−1}, bound grows to m(β−1), so require every p_i>m(β−1). For field extensions F_(p_i^d), these encoded digits lie in the prime subfields. This replaces I65's overflowing coefficient-form RS evaluations; it is NOT claiming any finite-field homomorphism across characteristics.

(B) **Restricted-domain distance.** For any distinct Boolean z,z', v=z−z'∈{−1,0,1}^m\{0}. Fix one nonzero v_j; condition on all random bits G_rk, k≠j, then P[(Gv)_r=0]≤1/2, because the two possible values differ by v_j≠0 in integers. Rows independent. Therefore #nonzero coordinates of Gv stochastically dominates Bin(M,1/2). The chance for a fixed v of weight <δM is at most 2^(−M(1−H2(δ))) by Chernoff/KL for δ<1/2. There are at most 3^m−1 distinct nonzero v, hence
  Pr_G[exists z≠z' with d_H(Gz,Gz')<δM] ≤ 3^m 2^(−M(1−H2(δ))).
For δ=1/8 and M=4m, 4*(1−H2(1/8))−log2(3)=0.240779726480458...>0. Hence Pr_bad≤2^(−0.2407797m), proving existence, with overwhelming probability at practical m. Since encoded integer values lie <p_i, nonzero integer differences cannot disappear under any CRT prime reduction: each field-projected code enjoys the same restricted-message support distance. This is a proof about differences between TWO BOUNDED INTEGER MESSAGES, NOT the minimum distance of the linear map on arbitrary F_(p_i)-vectors. A random integer binary G might have poor full-field linear-code properties; Brakedown's commitments need valid full-field code distance separately.

(C) **Conditional consistency sampling.** Suppose separately sound field-range checks establish for every CRT component k that the committed h^(k) is a legal digit vector, and a truly binding external commitment binds to ONE Boolean vector z. Suppose the prover additionally proves to the verifier, by a *yet-unconstructed reliable method*, that queried field codewords are G h^(k) and the queried external codeword is Gz. If h^(k)≠z for at least one field, then ≥δM encoded coordinates differ, so t independently sampled encoded indices miss the mismatch with probability ≤(1−δ)^t. At δ=1/8, t≥665 suffices for ≤2^-128 (under ideal perfect consistency at each sampled index). This is a CONDITIONAL implication and not an actual soundness proof; crucial commitments, codeword membership, opening relation, Merkle/hash binding, and adaptive transcript extraction not implemented.
For native q modulo several 49-bit primes, rings split into many CRT field factors; checking one codeword symbol against *all* factors has substantial PC costs. 665 coded opening probes are NOT directly comparable to 25 algebraic PIOP oracle queries, nor necessarily independent in Fiat–Shamir.

## Cost falsification at the paper-inspired scale
Take N=2^14, ell=1,c=1, beta=2, so m=2^ell*N*c=32768, M=4m=131072. A literal dense binary G has M*m=4,294,967,296 entries, even bitpacking gives 536,870,912 bytes (512MiB) for G alone. Naive evaluation needs Θ(mM)=Θ(m²) dot-product terms for each h (and repeated field projections), while original §4.3 prover is O(m+β), and §5's Brakedown target is linear/near-linear encoding. Matrix can be pseudorandomly generated from a small seed to avoid stored table but arithmetic stays dense unless additional exploitable structure is proved.
As an integer code of M symbols each needing ceil(log2(m+1))=16 bits, expansion over an m-bit Boolean message is 64× in bits; "symbol expansion M/m=4" does NOT mean information-theoretic bit-rate 1/4 as m grows. At p_i=49-bit commitments, representation may require the full 49-bit field symbol; concrete overhead larger.
Conditional 128-bit check count t=665 at δ=1/8; compare only qualitatively with 25 ring PIOP queries since different oracles/commitment semantics, not a valid direct benchmark. No source-grounded throughput gain, key memory gain, or efficient packed proof.
