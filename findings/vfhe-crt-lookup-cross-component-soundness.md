## Generality, impact, caveats
[THEOREM-LEVEL GENERALIZATION] This is NOT a pathology of tiny q=77: whenever a ring splits into at least two nontrivial CRT field factors, it contains a nontrivial idempotent e=(0,1,0,..) that is not a diagonal scalar 0 or1 but projects into fieldwise Boolean table {0,1}. For sufficiently large pmin and ell*, independently valid honest field memory traces can be CRT-glued to ring-valued polynomial witnesses. The same algebraic grand-product identity always holds (with no probabilistic error). This includes usual high-N proof-friendly ring designs with many extension-field factors, subject to allowed parameter choices. Merely growing exceptional S, increasing repetitions, assuming beta<pmin, or requiring b(b−1)=0 IN R does NOT rule out nontrivial CRT idempotents (since e²=e).
[PRECISE ERROR] The set tested componentwise is the larger **rectangular closure**
 `{x∈R: Phi^(k)(x)∈Phi^(k)(t_beta) for ALL k}`
not the required **diagonal** scalar set `t_beta={j*1_R:j=0..beta-1}`. The proof wrongly treats these as equal. This is more than a missing factor in Schwartz–Zippel: the polynomial difference is identically zero for an illegal input, so soundness amplification cannot help.
