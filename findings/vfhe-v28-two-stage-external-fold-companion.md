**Derivation:** For each native factor K_{i,j}=F_(p_i^d) and shared bounded a, define nonzero mismatch MLE D_{i,j}(X)=MLE(h_{i,j})−MLE(embed(a)). Under prebinding, some nonzero D has total degree≤ellstar. Draw random native ring point u from source-style exception set S of size pmin^d; Pr[D(u)=0]≤ellstar/pmin^d. For all L*N/d factors, expand each D_{i,j}(u) in d basis coordinates in F_(p_i), canonically lift those to [0,p_i−1] and embed in *unrelated* external F_r with prime r>max p_i, for M=L*N total coordinates z. Require a knowledge-sound cross-characteristic mapping proof and FIX z before independently sampling alpha←F_r. Check P_z(alpha)=∑_(t=0)^(M−1)z_t alpha^t=0. For true nonzero z, the root bound is (M−1)/r, so error ≤ellstar/pmin^d+(M−1)/r. This is ordinary Schwartz–Zippel plus canonical bounded integer injection, not a new cryptographic primitive.
