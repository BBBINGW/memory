## Exact analytical/arithmetical test [DERIVATION/COMPUTED]

Choose illustrative H=m=2^24=16,777,216 canonical beta4 digits, n=2 bits each; underlying bulletproof IPA length n*m=2^25, so k=log2(n*m)=25. But input **m commitments V_j** require m*32=**536,870,912 bytes = 512 MiB**, if transported as separate Pedersen group elements in THIS stock instantiation. Combined material is 536,872,800 bytes (512 MiB + 1,888 B), not O(log m). If those V_j were already committed and available independently in an *identical reusable* format, no repeated transfer is necessary; native F.2 Merkle/RS columns are a DIFFERENT scheme and do not constitute such existing V_j.

Comparison (same idealized 32-byte elements): naive V32 had 2H=33,554,432 separate bit Pedersen commitments (1GiB) plus 2H unaggregated OR-of-Schnorr transcripts of 192byte each (~6GiB), before native PCS and quotient CP.
